# MLP surrogate for 1D nonlinear ultrasound propagation in bubbly viscoelastic media

A small neural-network surrogate that predicts the amplitude of the second and third pressure harmonics, `(p2, p3)`, generated by a 1D nonlinear model of ultrasound propagating through a viscoelastic medium that contains gas bubbles, as a function of the source amplitude `p0` and the shear modulus `G` of the medium.

The surrogate is trained on simulations of a vectorized MATLAB solver (wave equation coupled to a volume-based Rayleigh-Plesset equation with Kelvin-Voigt viscoelasticity). It replaces a set of independent polynomial fits (one per value of `G`) by a single continuous surface `p2(p0, G)`, `p3(p0, G)`, and it can also be used to solve simple inverse problems (find the `p0` or the `G` that gives a target harmonic amplitude).

The 1D solver itself is not included in this repository. The dataset it produced is provided in `data/`, so the surrogate (training, evaluation, prediction and inversion) can be reproduced with the Python code alone.

It is part of my PhD research on the numerical modeling of nonlinear ultrasound interaction with gas bubbles in viscoelastic media (NANLA research group, Universidad Rey Juan Carlos). A 2D version of the solver and of the surrogate workflow is in a companion repository, [surrogate-modeling-EcRPvKV-WaveEq-2D](https://github.com/elenacarreras9/surrogate-modeling-EcRPvKV-WaveEq-2D).

## The model

The solver integrates, in a free-walled 1D cavity of length `L = lambda/4` (with `lambda = c_fbl / f` the wavelength in the bubbly medium), the wave equation for the pressure coupled to a volume-based Rayleigh-Plesset equation for the bubbles, in a Kelvin-Voigt viscoelastic medium. The scheme is explicit (leapfrog in time). The source is a pressure `p0 sin(2 pi f t)` at `x = 0` at `f = 200 kHz`. Bubble radius, bubble number density and the fluid properties are fixed in the solver.

Background on the formulation:

- E. V. Carreras-Casanova, C. Vanhille, *A Model for the Dynamics of Stable Gas Bubbles in Viscoelastic Fluids Based on Bubble Volume Variation*, Acoustics 2025, 7, 67.
- E. V. Carreras-Casanova, M. T. Tejedor-Sastre, C. Vanhille, *Nonlinear propagation of ultrasounds in bubbly viscoelastic media: Influence of medium properties on the nonlinear parameter*, Ultrasonics Sonochemistry 2025, 122, 107603.

## Pipeline

1. **Sound speed** `c_fbl` of the bubbly medium for each `G` (computed separately; `data/c_fbl1_table.csv`).
2. **Validity range of `p0` for each `G`** (`matlab/analyze_p0_limits.m`, `matlab/find_p0_max.m`, `matlab/find_p0_valid.m`). Two limits are computed: the numerical one (largest `p0` for which the scheme does not diverge) and the physical one (largest `p0` for which `epsilon = max|v| / V0 <= 0.5`, the validity criterion of the small-volume-change expansion). The smaller one is used. Result: `data/p0_limits_by_G.csv`.
3. **Dataset generation** (`matlab/generate_dataset_1d.m`): for each `G`, 25 values of `p0` between 500 Pa and 90% of the limit above, denser near the limit. Output: `data/dataset_1d_p2p3.csv` with columns `G_kPa, c_fbl1, p0_Pa, p2_Pa, p3_Pa`. The resulting dataset is provided in `data/`. The scripts of steps 2 and 3 call the 1D solver functions (`simulate_1d_harmonics.m` and `diag_vV0.m`), which are not included, so they are shown for reference and cannot be run from this repository alone.
4. **Training and evaluation** (`ml/`, PyTorch): see [ml/README.md](ml/README.md) for the design decisions.

## Repository structure

```
matlab/
  find_p0_max.m                numerical limit of p0 (bisection)
  find_p0_valid.m              physical limit of p0 (bisection on max|v|/V0)
  analyze_p0_limits.m          both limits for every G -> data/p0_limits_by_G.csv
  generate_dataset_1d.m        builds data/dataset_1d_p2p3.csv
data/                          c_fbl1 table, p0 limits per G and the dataset
ml/
  src/                         dataset, model, train, evaluate, predict, invert
  checkpoints/                 generated by train.py / evaluate.py (not versioned)
  requirements.txt
```

## How to run

MATLAB, from the `matlab/` folder (requires the 1D solver functions `simulate_1d_harmonics.m` and `diag_vV0.m`, which are not included in this repository):

```matlab
cd matlab
analyze_p0_limits()                          % Optional: p0 limits per G
generate_dataset_1d()                        % dataset (long: one sweep per G)
```

Python, from the `ml/` folder (the dataset is already in `data/`, so MATLAB is not needed):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows PowerShell
pip install -r requirements.txt
python src/train.py
python src/evaluate.py
python src/predict.py --G 33 --p0 25000 % Example
python src/invert.py --G 33 --p2 5000 % Example
```

## Known limitations

- `c_fbl` was computed exactly for only a few values of `G` (marked `exact` in `data/c_fbl1_table.csv`); the rest are interpolated.
- It is a 1D free-walled cavity, it does not correspond to the open-field cavity case.
- The surrogate has only two inputs, `p0` and `G`. Bubble radius, bubble number density and frequency are fixed in the solver.
- The surrogate is only valid inside the range of `p0` that each `G` was simulated with (up to the validity limit described above). `predict.py` and `invert.py` warn when asked to go outside it.
- The train/validation split is random over all rows. It measures interpolation between simulated points, not extrapolation to values of `G` that were not simulated.
