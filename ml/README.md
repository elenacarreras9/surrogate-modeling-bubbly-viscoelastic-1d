# MLP surrogate: (p0, G) -> (p2, p3)

A small network that learns, from `data/dataset_1d_p2p3.csv` (generated by `matlab/generate_dataset_1d.m`), the amplitude of the second and third pressure harmonics as a function of the source amplitude `p0` and the shear modulus `G`. It replaces a set of independent polynomial fits (one per value of `G`) by a single continuous surface p2(p0, G), p3(p0, G).

## Design decisions

- **A single network with two outputs** (not two separate networks): p2 and p3 come from the same nonlinear physics, so sharing the hidden layers makes better use of the available points.
- **Training on log(p2) and log(p3)** instead of the values in Pa: both span several orders of magnitude and grow roughly like a power of p0, so in log space the error is spread proportionally over the whole range instead of letting the high-p0 cases dominate the fit.
- **Standardization (mean 0, standard deviation 1)** of inputs and outputs (in log), fitted *only* on the training set, so that the validation set really measures the ability to generalize, without information leakage.
- **Fixed seeds everywhere** (train/validation split, DataLoader shuffling, weight initialization) for reproducibility.
- **Early stopping** (`patience`): if `val_loss` does not improve for 300 consecutive epochs, training stops and the weights of the best epoch are kept, not the last ones.

## Installation

From the `ml/` folder:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1      # extension .ps1, otherwise PowerShell does not run it
pip install -r requirements.txt
```

If `Activate.ps1` complains that script execution is disabled, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first (it only affects that PowerShell session).

## Usage

From the `ml/` folder (not from `src/`), with the environment activated:

```bash
python src/train.py
python src/evaluate.py
```

`train.py` reads `../data/dataset_1d_p2p3.csv`, trains, and saves in `checkpoints/`:

- `model.pt`: weights of the best model.
- `scalers.json`: input/output normalization and hyperparameters (everything needed to use the model without retraining).
- `history.json`: train/validation loss curves, useful to check for overfitting.

`evaluate.py` loads that checkpoint, measures the error on the validation set **in physical units** (Pa, not in the log-standardized training space; the relative error / MAPE is what matters given the range of magnitudes), writes `checkpoints/eval_metrics.json` and generates `checkpoints/prediction_vs_simulation.png`: simulated points (filled = training, ringed = validation, unseen by the network) with the MLP prediction superimposed.

Hyperparameters can be changed from the command line, for example:

```bash
python src/train.py --n_hidden 32 --n_layers 3 --n_epochs 5000
```

(see `python src/train.py --help` for the full list).

## Predict and invert

```bash
python src/predict.py --G 33                 # full curve p2(p0), p3(p0) for G = 33 kPa
python src/predict.py --G 33 --p0 25000      # a single point
python src/invert.py --G 33 --p2 5000        # which p0 gives p2 = 5000 Pa at G = 33 kPa?
python src/invert.py --p0 25000 --p2 5000 --p3 450   # which G best reproduces both targets?
```

Both scripts search only within the range of `p0` (and `G`) that the network saw in training, and warn when the request falls outside it or when the solution of the inverse problem lies at the edge of the range.

## Using the trained model from another script

```python
import torch, json
from src.dataset import Scaler, predict_physical
from src.model import SurrogateMLP

with open("checkpoints/scalers.json") as f:
    meta = json.load(f)
model = SurrogateMLP(n_hidden=meta["n_hidden"], n_layers=meta["n_layers"])
model.load_state_dict(torch.load("checkpoints/model.pt"))
x_scaler = Scaler.from_state_dict(meta["x_scaler"])
y_scaler = Scaler.from_state_dict(meta["y_scaler"])

p2, p3 = predict_physical(model, x_scaler, y_scaler, p0_Pa=25000, G_kPa=37)
```
